# Security Policy

## Supported versions

Only the latest default branch is currently supported because the project is in early development.

## Reporting a vulnerability

Please do not disclose security issues in a public issue. Use GitHub Security Advisories if enabled for the repository, or contact the maintainers privately through the repository owner’s published contact channel.

Include a description, affected files or versions, reproducible steps, and potential impact. Do not include passwords, API keys, private keys, personal data, or other secrets in reports.

## Scope

The application is currently a local calculation tool and does not require a backend, account, or API key. Reports about incorrect engineering assumptions should be filed using the engineering-data issue template rather than treated as software vulnerabilities.
